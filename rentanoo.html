Sous le capot

La complexité technique cachée

Sécurité multi-tenant
RLS Supabase par propriétaire
Chaque loueur voit et modifie uniquement ses propres données. Row Level Security côté PostgreSQL — aucun filtre côté client.
CREATE POLICY "owner_only" ON vehicles USING (owner_id = auth.uid())
Social preview
OG injection server-side
Express détecte les bots Facebook / WhatsApp / Twitter et injecte les balises OG dynamiques avec la vraie photo du véhicule avant de servir le HTML.
facebookexternalhit|whatsapp|twitterbot → inject og:image, og:title
Requêtes DB
Supabase RPC pour UUID → licence
Le filtre ILIKE sur UUID échoue à cause de l'encodage URL des % par le client JS. Solution : fonction SQL RPC qui contourne via JSON body.
supabase.rpc("get_vehicle_by_license", { p_license })
Anti double-booking
Vérification temps réel avant paiement
Avant chaque paiement Stripe, une vérification de disponibilité côté serveur. Si le créneau est pris entre la sélection et le paiement, la réservation est bloquée.
CHECK availability → CREATE booking → CHARGE stripe (atomique)
Automatisation
Chain N8N 5 étapes
Chaque événement réservation déclenche : confirmation email client, notification propriétaire, mise à jour planning, génération PDF EDL, archivage.
Webhook → Email → Planning → PDF → Archivage
Internationalisation
i18n UI + traduction contenu à la demande
Interface 4 langues (i18next). Descriptions véhicules traduites en DB ou à la volée via MyMemory API — bouton "Traduire" n'apparaît que si la traduction manque.
stored_translation ?? await /api/translate (MyMemory)

Apprentissages

Leçons apprises

01

La réservation ouvre le marché

Les EDL et la maintenance créent le plus de valeur — mais la réservation en ligne est le déclencheur qui rend tout le reste pertinent.

02

Complexité business > complexité technique

La gestion de flotte, les modèles de tarification dynamique et les règles de disponibilité sont plus difficiles à modéliser que n'importe quel défi technique.

03

L'automatisation multiplie la valeur

N8N transforme un back-office en système opérationnel. Chaque automatisation libère du temps et réduit les erreurs humaines.
