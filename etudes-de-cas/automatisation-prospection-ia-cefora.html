Écosystème CEFORA — prospection + RH + commercial

Contexte client

CEFORA est un acteur de la formation professionnelle avec une équipe commerciale de sept personnes chargées de développer le portefeuille entreprises — OPCO, PME, grands comptes régionaux. Le modèle économique repose sur le remplissage des promotions : chaque semaine sans pipeline suffisant coûte en CA et en charge fixe. L'équipe passait un temps considérable à construire manuellement des listes, enrichir des contacts LinkedIn, rédiger des emails de premier contact et mettre à jour le CRM.

Objectif : multiplier le volume de prospection sortante sans embauche, tout en maintenant la qualité de ciblage formation. Secondaire : accélérer le tri des candidatures RH via l'agent Rebecca sur le même stack automation.

Diagnostic initial

  • Prospection manuelle : ~700 entreprises/semaine max, fatigue équipe
  • Données dispersées : Excel, CRM partiel, notes email
  • Pas de séquençage automatique — relances oubliées
  • RH saturée par tri CV manuel (pipeline Rebecca opportun)

Solution déployée

Pipeline prospection n8n

Workflow 1 — Enrichissement : import bases cibles, API enrichissement (siret, secteur, taille, contacts), dédoublonnage, scoring ICP formation.

Workflow 2 — Séquençage : emails personnalisés Claude, relances J+3/J+7, arrêt automatique sur réponse ou opt-out.

Workflow 3 — Routing : attribution round-robin aux 7 commerciaux selon secteur et charge, notification Slack/email, tâche CRM créée automatiquement.

Workflow 4 — Reporting : dashboard hebdo volume, taux ouverture, RDV bookés, pipeline €.

Agent Rebecca (RH parallèle)

Même mission : CV → GPT-Vision → Airtable, 35 h/semaine économisées. Voir automatisation RH et projet Rebecca.

Résultats

  • +70 % prospection — volume hebdomadaire entreprises contactées
  • 1200 entreprises/semaine en régime de croisière
  • 7 commerciaux focalisés closing et RDV, moins admin
  • +60 % réactivité sur leads entrants (synergie Rebecca + routing)
  • 2 ETP équivalent automatisés sur tâches répétitives

Stack & méthode

n8n (orchestration), Claude API (personnalisation emails), Airtable/CRM, MAKE certifié pour connecteurs complémentaires. Déploiement en 3 phases sur 8 semaines : pilote 2 commerciaux → extension 7 → Rebecca RH. Formation handover incluse.

Leçons réutilisables

Ce cas démontre qu'une PME/ETI formation — ou tout B2B avec équipe 5–10 commerciaux — peut doubler virtually sa prospection sans recrutement si le process est modélisé avant d'être automatisé. La clé n'est pas l'outil mais le ciblage ICP calibré avec la direction commerciale avant une ligne de code n8n.

Timeline projet CEFORA

S1–S2 : ateliers ICP, audit CRM, choix segments prioritaires. S3–S4 : pilote enrichissement + séquences sur 2 commerciaux, mesure taux bounce et réponses. S5–S6 : extension 7 commerciaux, routing round-robin, dashboard direction. S7–S8 : déploiement Rebecca RH en parallèle, formation ops, documentation handover. Résultat steady-state : 1200 entreprises/semaine, +70 % vs baseline prospection manuelle mesurée S1.

Stack détaillé par workflow

Enrichissement : n8n Schedule → API entreprises → Function node scoring → Airtable base prospects. Séquençage : n8n Wait nodes → Claude HTTP Request personnalisation → SMTP/API email → webhook unsubscribe. Routing : Switch node secteur → Set node commercial_id → CRM API create task → Slack notify. Chaque workflow isolé pour maintenance sans casser les autres — best practice expert n8n documentée sur expert-n8n.html.

FAQ

CEFORA est-il joignable comme référence ?

Référence sur demande après accord client. Chiffres agrégés présentés ici sont contractuels projet.

Reproductible pour combien de commerciaux ?

Architecture scalable 3–20 commerciaux. Au-delà : sharding workflows et queue mode n8n.

Quel délai de déploiement ?

8 semaines CEFORA (prospection + Rebecca). Pilote prospection seul : 3–4 semaines.

Emails automatisés = spam ?

Personnalisation Claude, ciblage ICP strict, opt-out, volume progressif warm-up. Taux ouverture monitoré.

Budget indicatif ?

25 €/h · projet CEFORA scope multi-workflow. Devis après audit 30 min gratuit.

Compatible LinkedIn Sales Nav ?

Oui avec respect ToS — enrichissement via APIs tierces où Sales Nav export limité.

Et la prospection téléphonique ?

Workflow génère listes priorités + scripts pour commerciaux. Maestro complète post-appel (demo).
