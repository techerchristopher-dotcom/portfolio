À propos du projet

L'agent qui analyse 100+ CVs automatiquement

Agent Rebecca est un pipeline d'automatisation RH déployé en production chez CEFORA. Il analyse automatiquement les CVs reçus par email ou formulaire, extrait les informations clés via GPT-Vision, les classe, et les injecte dans Airtable.

[ Description détaillée à compléter — contexte chez CEFORA, volume traité, types de formations visées, critères de classification, résultats observés. ]

  • Réception automatique des CVs via email ou formulaire web
  • Conversion PDF → JPEG via iLovePDF + Picnie pour analyse visuelle
  • Analyse GPT-Vision : extraction nom, email, compétences, zone géographique
  • Classification IA : formation visée, pertinence du profil, score de matching
  • Injection automatique dans Airtable avec stockage Drive + notification équipe
