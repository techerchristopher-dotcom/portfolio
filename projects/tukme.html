À propos du projet

L'application VTC pensée pour Nosy Be

Tukme est une application mobile de réservation de tuk-tuks développée avec React Native + Expo pour l'application passager, et Next.js pour le panel d'administration web.

[ Description détaillée à compléter — contexte, problème résolu, choix techniques, défis rencontrés. ]

  • Géolocalisation et carte interactive temps réel (Google Maps / Routes API)
  • Paiement Stripe PaymentSheet avec Edge Functions Deno hébergées sur Supabase
  • Gestion chauffeur & passager avec synchronisation temps réel via Supabase Realtime
  • Push notifications Expo pour alertes de course
  • Panel admin Next.js pour la gestion des courses et des utilisateurs
A→Z Projet full-scale conçu seul
3 interfaces : passager, chauffeur, admin
RT Synchronisation temps réel
