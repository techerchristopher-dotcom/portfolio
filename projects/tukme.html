Tukme

📱 MobileVTC · Fintech ⏳ En cours

Application VTC mobile complète pour commander un tuk-tuk depuis son smartphone. Géolocalisation temps réel, paiement Stripe in-app, gestion chauffeur/passager séparée, panel admin Next.js. Full-scale de A à Z.

2 apps passager + chauffeur
RT géolocalisation temps réel
Stripe paiement in-app

Projet

Ce que ça fait

  • 2 apps distinctes — passager et chauffeur, chacune avec ses flows propres
  • Géolocalisation temps réel — Supabase Realtime + Google Maps Routes API
  • Paiement natif — Stripe PaymentSheet via Edge Functions Deno sur Supabase
  • Push notifications — Expo Notifications pour alertes courses/statuts
  • Panel admin web — Next.js pour gestion complète côté opérateur
  • Architecture monorepo — app mobile + admin partagent la même BDD Supabase
