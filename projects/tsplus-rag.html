TSplus RAG

🤖 IARAG · Supabase ● Live

Architecture RAG complète pour vectorisation et recherche sémantique sur documents internes. Déployé en production pour TSplus — les documents sont transformés en vecteurs, stockés dans pgvector, et requêtables par similarité sémantique.

RAG architecture complète
pgvector recherche sémantique
∞ documents indexables

Projet

Ce que ça fait

  • Ingestion flexible — tout type de document découpé en chunks indexables
  • Embeddings OpenAI — vectorisation via API, stockage permanent dans pgvector
  • Recherche sémantique — similarité cosinus, pas de keyword matching
  • Architecture RAG — le LLM reçoit le contexte pertinent avant de répondre
  • Supabase infra — PostgreSQL + pgvector, scalable, pas de vector DB tiers
