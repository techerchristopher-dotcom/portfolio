Anti-patterns que je corrige souvent

Workflow monolithique — un seul canvas de 80 nodes impossible à maintenir. Je découpe en sub-workflows testables. Pas d'error workflow — une API down et tout s'arrête silencieusement. J'ajoute branches erreur + alertes Slack. Secrets en dur — credentials n8n ou env vars, jamais en clair dans les nodes. Pas d'idempotence — double webhook = double email client ; j'implémente des clés dedup. Logging absent — impossible de debugger en prod ; j'ajoute des inserts Airtable/Notion trace ou stdout structuré.

Ces corrections transforment un POC « qui marche quand on regarde » en système 7j/7 — condition sine qua non pour livrer en production avec des KPI comme Maestro (<10 s) ou Rebecca (35 h/sem).

Self-hosted vs n8n cloud — recommandation

Pour les clients Océan Indien avec données sensibles (CV, enregistrements appels), je recommande souvent n8n self-hosted sur VPS EU avec backups quotidiens — coût infra < 50 €/mois pour la plupart des volumes. n8n cloud accélère le time-to-market si pas de contrainte souveraineté.
